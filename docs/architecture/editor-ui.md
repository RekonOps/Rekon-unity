# M5 에디터 UI 설계 문서

## 개요

Rekon Unity 플러그인의 에디터 UI 레이어 설계 문서입니다.
설정 패널, Play Mode 오버레이, 번들 관리 윈도우 3개 영역으로 구성됩니다.

---

## 1. 설정 패널 (RekonSettingsWindow)

**메뉴 경로**: `Window/Rekon/Settings`

### 와이어프레임

```
┌──────────────────────────────────────────────────────────────────┐
│  Rekon Settings                                    [X]    │
├──────────────────────────────────────────────────────────────────┤
│  [ General ] [ Video ] [ Crash Recovery ] [ Advanced ] [ Jira ]  │
├──────────────────────────────────────────────────────────────────┤
│                                                                  │
│  ▼ General                                                       │
│  ┌────────────────────────────────────────────────────────────┐  │
│  │  Capture Hotkey      [ F12 ▼ ]                             │  │
│  │  Screenshot Downscale [ 1   ▼ ]   (1=원본, 2=절반, ...)    │  │
│  │  Log Buffer Size      [ 500    ]  (100~5000)               │  │
│  └────────────────────────────────────────────────────────────┘  │
│                                                                  │
│  (General 탭 예시)                                               │
│                                                                  │
│  ─────────────────────────────────────────────────────────────   │
│  [ Apply ] [ Revert ]                                            │
└──────────────────────────────────────────────────────────────────┘
```

### 탭별 구성

| 탭 | 필드 |
|----|------|
| General | 캡처 핫키(KeyCode), 스크린샷 다운스케일(1~4), 로그 버퍼 크기(100~5000) |
| Video | 영상 활성화 토글, 해상도(W/H), FPS(15~60), 버퍼 시간(10~120초), 비트레이트(2~20Mbps) |
| Crash Recovery | 로그 플러시 간격(1~30초), 상태 플러시 간격(1~60초), 영상 플러시 간격(10~120초), 최대 크래시 번들(1~50), 보관 일수(1~365) |
| Advanced | 최대 번들 수(10~1000), 최대 디스크 용량(500~20000MB), Auth Broker URL |
| Jira | 연결 상태, 연결/해제 버튼, Site URL, 기본 라벨 목록 |

## 2. ~~Jira 연결 패널 (JiraConnectionPanel)~~ — 제거됨

> PLG 전환으로 Jira 연결 기능이 웹 대시보드로 이관되어 Unity 플러그인에서 삭제되었습니다.

## 3. Play Mode 캡처 오버레이 (CaptureOverlay)

**위치**: 화면 우하단 고정
**구현**: IMGUI (OnGUI), MonoBehaviour, DontDestroyOnLoad

### 와이어프레임 - 캡처 시작 플래시

```
┌────────────────────────────────────────────────────┐
│ ████████████████████████████████████████████████   │ ← 상단 가장자리 녹색 테두리
│ █                                                █  │
│ █                  게임 화면                      █  │
│ █                                                █  │
│ █                                                █  │
│ █                                                █  │
│ ████████████████████████████████████████████████   │ ← 하단 가장자리
└────────────────────────────────────────────────────┘
  (녹색 플래시 0.3초 표시 후 자동 소멸)
```

## 5. 번들 관리 윈도우 (BundleManagerWindow)

**메뉴 경로**: `Window/Rekon/Bundles`

### 와이어프레임

```
┌──────────────────────────────────────────────────────────────────┐
│  Rekon Bundle Manager                              [X]    │
├──────────────────────────────────────────────────────────────────┤
│  필터: [ 전체 ▼ ]          [ 새로고침 ]   디스크: 128 MB / 5 GB  │
├──────────────────────────────────────────────────────────────────┤
│  날짜/시간              제목                       상태           │
│  ─────────────────────────────────────────────────────────────   │
│  2024-01-15 10:30      로그인 버튼 클릭 시 앱 크래시  [생성됨]   │
│    [ Jira 제출 ] [ 삭제 ] [ 폴더 열기 ]                          │
│  ─────────────────────────────────────────────────────────────   │
│  2024-01-15 09:15      UI 텍스트 깨짐 현상          [대기중]     │
│    [ Jira 제출 ] [ 삭제 ] [ 폴더 열기 ]                          │
│  ─────────────────────────────────────────────────────────────   │
│  2024-01-14 18:00      NPC 이동 경로 버그            [성공]      │
│    [ 삭제 ] [ 폴더 열기 ]                                        │
│  ─────────────────────────────────────────────────────────────   │
│  2024-01-14 15:22      사운드 끊김                   [실패]      │
│    [ 재시도 ] [ 삭제 ] [ 폴더 열기 ]                             │
│  ─────────────────────────────────────────────────────────────   │
├──────────────────────────────────────────────────────────────────┤
│  [ 보관 정책 적용 ]                                               │
└──────────────────────────────────────────────────────────────────┘
```

### 상태 배지 색상

| 상태 | 색상 | 한글 |
|------|------|------|
| Created | 회색 `#808080` | 생성됨 |
| Pending | 노랑 `#FFA500` | 대기중 |
| Submitting | 파랑 `#4488FF` | 제출중 |
| Submitted | 초록 `#44BB44` | 성공 |
| Failed | 빨강 `#FF4444` | 실패 |

### 필터 옵션

| 필터 | 표시 대상 |
|------|-----------|
| 전체 | 모든 번들 |
| 미제출 | Created, Pending, Failed |
| 제출됨 | Submitted |
| 실패 | Failed |

## 6. 파일 구조

```
Editor/
  UI/
    RekonSettingsWindow.cs   - 설정 EditorWindow (탭 포함)
    BundleManagerWindow.cs         - 번들 관리 EditorWindow

Runtime/
  UI/
    CaptureOverlay.cs              - Play Mode 캡처 오버레이 (IMGUI)

Tests/
  Editor/
    UI/
      BundleManagerWindowTests.cs  - 번들 관리 UI 에디터 테스트
  Runtime/
    UI/
      CaptureOverlayTests.cs       - 캡처 오버레이 Play Mode 테스트
```

---

## 7. 의존성 관계

```
RekonSettingsWindow
  ├── RekonSettings (ScriptableObject)
  └── SerializedObject/SerializedProperty (Undo 지원)

BundleManagerWindow
  └── BundleRepository (번들 목록/상태 조회)

CaptureOverlay
  └── CaptureOrchestrator.OnProgress (이벤트 구독)

BugReportForm — 제거됨 (PLG 전환으로 웹으로 이관)
```
